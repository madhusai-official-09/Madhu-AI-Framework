## ✨ Features

- 💬 AI Chat
- ⚡ Streaming Responses
- 📄 PDF Knowledge Base
- 📚 RAG (Retrieval Augmented Generation)
- 🧠 Conversation Memory
- 🔎 ChromaDB Vector Store
- 🌐 FastAPI REST API
- ⚛️ React SDK
- 📝 Markdown Rendering
- 💻 Code Syntax Highlighting
- 📂 Multiple Chats
- 📎 File Upload
- 🖥 CLI
- 🪶 Lightweight
- 🚀 Built on Groq
